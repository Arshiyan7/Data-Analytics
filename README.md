# Data Analytics Portfolio

A collection of data analytics projects demonstrating end-to-end skills across Python, SQL, Excel, and Power BI. Each project covers real-world datasets with a focus on data cleaning, exploratory analysis, business question answering, and dashboard building.

---

## Projects

| Project | Description | Tools |
|---|---|---|
| [Olist E-Commerce Analytics](https://github.com/Arshiyan7/Data-Analytics/tree/master/Olist_Analyst_project) | End-to-end analytics pipeline on real-world Brazilian e-commerce data covering data cleaning, SQL analysis, Excel dashboard, and Power BI dashboard | Python, SQL, Excel, Power BI |
| [Netflix EDA](https://github.com/Arshiyan7/Data-Analytics/tree/master/Netflix_EDA) | Exploratory data analysis on Netflix content library uncovering growth trends, top countries, and content demographics | Python, Pandas, Matplotlib, Seaborn |
| [Netflix SQL Analysis](https://github.com/Arshiyan7/Data-Analytics/tree/master/netflix-postgresql-analysis) | SQL analysis of Netflix dataset answering 10 business questions using PostgreSQL | PostgreSQL, pgAdmin |
| [FIFA 24 EDA](https://github.com/Arshiyan7/Data-Analytics/tree/master/FiFa24_EDA) | Exploratory analysis of FIFA 24 player statistics covering performance metrics, value distribution, and position analysis | Python, Pandas, Matplotlib, Seaborn |
| [COVID-19 Power BI Dashboard](https://github.com/Arshiyan7/Data-Analytics/tree/master/Covid-19-Powerbi-dashboard) | Interactive dashboard analyzing global COVID-19 cases, deaths, and recoveries across countries and time | Power BI, DAX |
